# ArkniyaTRP — «Блаженная Аркнийская Империя»

Фан-проект: текстовая РПГ с ИИ-Мастером по миру игр Schisma Games / 101XP
«Жизнь и страдания господина Бранте» и «Принц Джериан». Цель — не уступать оригиналу
по верности лору, глубине механик и эстетике. Деплой — GitHub Pages, ветка `workinprogress`.

**Автор проекта — одновременно его игрок.** Не показывай ему сгенерированную прозу сцен,
тексты концовок и сюжетные повороты без прямой просьбы: это спойлеры для него самого.
Техническое (код, структура, числа, проверки) — можно.

## Как со мной работать

- Всё — по-русски. Команды короткие («делай», «давай», «читай»): выводи задачу из контекста,
  не переспрашивай по мелочам. Спрашивай только о решениях по канону и замыслу.
- Сдаю только изменённые файлы, не архивы целиком.
- Перед сдачей: `npm test` (он же `node tests/rt.js`) — должно быть 0 сбоев.
  Для `app.js` отдельно: `node --input-type=module --check < assets/app.js`.
- Никаких правок срезами по индексам (`s[a:b]` без проверки якоря) — так дважды терялись куски кода.
  Замены — только по точному тексту с проверкой, что он встречается ровно один раз.
- `app.js` — собранный бандл (React внутри), не минифицирован. Исходников `src/` нет,
  поэтому правим прямо бандл. Внутри промпта Мастера шаблонные строки (`` ` ``) соседствуют
  с обычными — подстановка `${}` работает только в шаблонных, проверяй границы литерала.
- Ничего не выдумывать: подписи, звания, пороги, лор — только из источников.
  Непроверенное помечать: **[К]** канон, **[В]** выведено из канона, **[Р]** реконструкция.
  Расхождения источников не решать молча — выносить на решение.

## Структура

```
index.html            порядок скриптов важен (см. ниже)
assets/boot.js        картинки: ARK_ICONS, ARK_ARMS, ARK_MAP (путь к старой карте!)
assets/ark-eras.js    ARK_ERAS — единственный источник эпох (7 штук), хроника, ЕСТЬ/НЕТ/ТОН,
                      роли источников по годам, arkPromptEra(год, месяц) — блок эпохи для Мастера
assets/ark-scales.js  ARK_TRAITS / ARK_SKILLS / ARK_ESTATES — единая таблица имён; шкалы, звания,
                      карточки справки, ARK_BOOK (книжный разворот), куски промпта из таблиц
assets/ark-rules.js   ARK_RULES — библия проекта, высший приоритет
assets/ark-lore.js    ARK_CANON — артбук «Принца Джериана» со ссылками на страницы
assets/ark-map.js     ARK_GEO — география официальной цифровой карты (сейчас только данные,
                      в интерфейсе стоит старая карта — так решено)
assets/ark-script.js  ARK_SCRIPT — поиск по скрипту Бранте (script/blocks.json)
assets/ark-jerian.js  ARK_JERIAN — поиск по сценам Джериана (jerian/scenes.json — НЕТ, см. ниже)
assets/ark-wire.js    ARK_WIRE — сборка системных блоков Мастера и справки из текстов игр
assets/app.js         игра (type="module", выполняется после всех обычных скриптов)
script/blocks.json    скрипт Бранте, 16 817 блоков, пересобран из russian.txt [Р]
tests/rt.js           проверки сборки
```

Порядок в `index.html`: boot → ark-eras → ark-scales → ark-rules → ark-lore → ark-map →
ark-script → ark-jerian → ark-wire → app. `ark-eras` обязан быть раньше `ark-scales`.

**Имена глобалов не трогать без нужды:** `ARK_MAP` занят путём к картинке (boot.js),
`ARK_LORE` — `const` внутри app.js. Поэтому модули зовутся `ARK_GEO` и `ARK_CANON`.

## Как собирается наказ Мастеру

Системные блоки сверху вниз (по убыванию приоритета):
1. `ARK_RULES.system()` — библия;
2. `ARK_LORE` — канон проекта (const в app.js: быт, дворянство, типажи);
3. артбук (`ARK_CANON`) — целиком для лет с 1121, до 1121 только вневременные темы (аркны, смерть);
   кеш (`cache_control`) стоит на этом блоке — всё выше него статично;
4. наказ `Cp` + блок эпохи (`arkPromptEra`) + состояние героя + справка из скрипта Бранте.

Справка подбирается **до** запроса по действию игрока (не tool use) — работает у всех
провайдеров, ответ Мастера остаётся чистым JSON.

## Эпохальный фильтр — главный принцип

Источники описывают разные эпохи одного мира. **Мастер не знает ничего позже текущего дня партии.**
- В вечных блоках (МИР, ARK_LORE, библия) — никаких дат из будущего. Тест проверяет.
- Хроника (`ARK_ERAS.chrono`) отдаётся только до текущего года и месяца.
- Роль источника по году: canon / history (только как память, предание) / future (не использовать).
  Бранте 1121–1148, Джериан 1130–1150, артбук 1121–1150, «Талисман-9,5: Реквием» 1166–1182.

## Решённый канон

- **Смерти:** четыре малые, пятая — истинная (решено 15.08: правила T-9,5, «Мир Талисмана»,
  артбук с. 70). Смерть Императора всегда истинная.
- **Основатель Империи** — Джориан Тэмпест-Спаситель; второй Император — его брат
  Корнелий Тэмпест-Марк-Завоеватель.
- **Аркны — раса, не сословие**; стать аркном нельзя. При создании героя — около 3%.
- **Магия и чудеса Близнецов — разные силы.** Бранте — только чудеса и только на пути священника.
  Магия не исчезала полностью: уцелевшие маги прячутся, их укрывают еретики и часть знати.
  Закон о магии зависит от эпохи.
- **Два восстания:** местное в Анизотти (1146) и Великое (с 1148).
- **Навыки:** «Тайные планы», не «Схемы»; черта «Находчивость», не «Изобретательность».
- Разделы книги: Личность, Род, Провинция(Карта), Дело; Квестов нет. Справа не больше пяти закладок;
  Восстание — только если мятеж объявлен, Дар — только если есть магия или чудеса.

   Сейчас держимся 1166; записано в спорных местах `ark-rules.js`.

   хотя Древо гибнет 30 Красного.

4. Написание: «Миланид» (игры, официальная карта) против «Меланид» (лор проекта). Не унифицировано.
5. Продолжительность жизни аркна: 400 (артбук) против 500 (lore_arkniya_expanded). Библия — 500.
6. Название Столпа: «Сверкающий» (артбук) против «Сияющий» (скрипт Бранте).
